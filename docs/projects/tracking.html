02 / 실무 · 문제 진단

전화 클릭 전환 중복 차단

GA4 / GTM · 수정 코드·저장 스크립트 기준

내 역할 AI를 통한 수정 실행 · 본인 검토

문제

기존 코드와 GTM이 전화 클릭 전환을 각각 전송할 수 있음

판단과 행동

신규 전환 이벤트 번호만 바꿔서는 기존 전송이 사라지지 않으므로, 중복을 만드는 기존 호출 경로를 차단했습니다.

확인된 결과

기존 호출 차단과 phone_click 유지 내용을 코드로 확인

작업 근거

원본 내용을 익명화·요약한 자료
수정 코드 요약
수정 전기존 호출 + GTM 전송 경로
수정 후기존 호출 차단
phone_click 이벤트 유지
보관 코드 기준 · 현재 라이브 검증 아님

근거: 보관 코드와 GTM 저장 스크립트, 역할은 본인 확인. 당시 실행 로그가 없어 코드 검토 결과와 실제 동작 검증을 구분합니다. 상담 증가 효과는 산정하지 않았습니다.

실제 판단 사례

차단할 전송과 유지할 이벤트를 구분

수정 전후 코드 차이 및 보관된 GTM 스크립트 요약
검토 항목수정 자료에서 확인되는 내용
기존 전송wcs.cnv 호출과 wcs_do 전송 코드 제거
유지할 기록phone_click DataLayer 이벤트 유지
적용 범위GTM 저장 코드에 특정 페이지 한정 조건 존재

보관 자료를 익명화해 재구성했습니다.

관찰

기존 함수 안에는 wcs.cnv 호출·wcs_do 전송과 phone_click 이벤트 기록이 함께 있었습니다. 전환 번호를 바꾸는 것만으로는 별도의 기존 전송 경로가 사라지지 않습니다.

판단

전송 경로와 클릭 기록을 나눠 기존 호출만 차단하는 수정안을 설명할 수 있도록 정리했습니다. 이 표는 보관 코드의 검토 근거입니다.

실행·다음 검증

AI를 활용해 수정 작업을 실행하고 검토했습니다. 아래 발췌에서는 페이지 식별값을 생략했습니다.

수정 전

wcs.cnv("2", "1");
wcs_do(_nasa);
dataLayer.push({ event: "phone_click", ... });

수정 후

// 기존 wcs 전송 제거
dataLayer.push({ event: "phone_click", ... });

원본 diff의 핵심 경로를 축약한 비실행 코드입니다. 생략 기호(...)는 페이지 식별값 등 생략을 뜻합니다.

확인 범위

코드 변경 내역과 저장 스크립트를 확인했습니다. 당시 Preview·네트워크 원시 로그 및 반복 클릭 테스트 결과는 이 자료에 포함되지 않았습니다.

자세한 수행 과정

01 / Overview

프로젝트 개요

랜딩페이지의 전화 클릭에 기존 전환 코드와 GTM 전환이 함께 작동하는 구조를 다룬 사례입니다.

02 / Problem

문제

전화 클릭 시 기존 wcs.cnv 호출이 남아 있으면 GTM의 신규 전환과 별도로 전송될 수 있었습니다. 이벤트 번호 변경만으로는 기존 경로를 제거할 수 없는 구조였습니다.

03 / Goal

목표

전화 클릭 기록을 유지하면서 해당 페이지의 기존 중복 전환 전송을 차단하는 것이 목표였습니다.

04 / My Role

내 역할

AI를 활용해 중복 차단 작업을 실행하고 수정 내용을 검토했습니다. 광고 운영자로서의 검토와 AI를 통한 구현을 함께 수행한 사례입니다.

05 / Analysis

분석 근거

수정 전후 코드에서 기존 wcs.cnv 및 wcs_do 전송 경로와 phone_click 이벤트를 구분했습니다. 적용 범위를 특정 페이지와 전화 클릭으로 제한하는 조건을 검토했습니다.

06 / Action

실행과 제안

기존 전환 전송을 차단하고 phone_click DataLayer 이벤트를 유지하는 수정을 AI로 실행·검토했습니다. 보관된 GTM 스크립트에서 페이지 한정 차단 코드를 확인할 수 있습니다.

07 / Result

결과와 한계

기존 전송 제거와 phone_click 유지가 나타나는 코드 변경 내역, 페이지 한정 차단 조건이 포함된 GTM 저장 스크립트가 남아 있습니다.

08 / Insight

배운 점

전환 이름이나 번호보다 전송 경로를 확인해야 합니다. AI가 만든 수정도 적용 범위와 유지해야 할 이벤트를 기준으로 검토해야 합니다.
